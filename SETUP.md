## Getting Started

### 1. Navigate to the project
```bash
cd /home/claude/bubu-ipsum
```

### 2. Start the development server
```bash
npm run dev
```

This will start Vite dev server (usually on http://localhost:5173)

### 3. What you'll see
Right now you'll see the default Vite + React starter page with the Vite logo and a counter button.
