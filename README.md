# Bubu Ipsum

A chaotic lorem ipsum generator with culturally relevant vibes. Generate placeholder text flavored as LinkedIn thought leadership, AI slop, extremely online discourse, tech bro pitches, and more.

## Getting Started

```bash
npm install
npm run dev
```

Opens at `http://localhost:5173`.

## Usage

1. **Choose a vibe** — pick from 10 text styles (or use Classic Lorem Ipsum for clean mode)
2. **Adjust the controls** — set paragraph count and length
3. **Copy the output** — use it as placeholder text in mockups, prototypes, or wherever lorem ipsum lives

## Stack

- React + Vite
- `src/data/vibes.js` — all text content lives here; add new vibes by extending the `VIBES` object
